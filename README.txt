RUANGSABLON — TEMPLATE WEBSITE JASA SABLON KAOS

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder website_sablon_custom.
3. Klik dua kali index.html untuk melihat website di browser.
4. Untuk mengubah tampilan, edit style.css.
5. Untuk mengubah teks, nama brand, dan konten, edit index.html.

WAJIB DIUBAH SEBELUM DIPUBLIKASIKAN
- Ganti nama "RuangSablon" dengan nama usaha/klien.
- Buka script.js dan ganti WHATSAPP_NUMBER dengan nomor admin yang benar.
  Format: kode negara 62, tanpa tanda +, spasi, atau tanda hubung.
- Ganti gambar demo dengan foto produk/hasil sablon milik bisnis.
- Sesuaikan deskripsi, alamat, layanan, harga, dan informasi garansi dengan data usaha sebenarnya.

CATATAN
- Foto pada template memakai URL gambar eksternal dari Unsplash dan memerlukan koneksi internet.
- Website ini merupakan template inspirasi untuk jasa sablon kaos, bukan salinan persis situs KedBel.
- Tidak termasuk backend, database, formulir pesanan tersimpan, atau sistem pembayaran.
